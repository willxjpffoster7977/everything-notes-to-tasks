## What is EVERYTHING?

EVERYTHING is a browser-based planning and organization tool built for the moment when ideas, reminders, and notes are all mixed together. Enter a quick brain dump, then arrange the contents into tasks, events, and projects without creating an account or depending on a server.

The application is delivered as one HTML file, making it simple to run in a browser and suitable for lightweight personal workflows. Your information remains on the device in use, and the app can continue operating offline once it has been loaded for the first time.

## Using EVERYTHING

Begin by placing your thoughts, ideas, and reminders in the input area. Once captured, review the entries and assign them to the appropriate tasks, events, or projects. You can then refine the app's sections, presets, colors, and sorting behavior around the way you work.

A practical cycle looks like this:

- Record everything without organizing immediately
- Sort and structure the captured information afterward
- Keep reusing the layout and rules that suit your workflow
- Export a backup from settings whenever you want to preserve the current setup

## Frequently Asked Questions

**Do I need to sign up?**  
No. EVERYTHING does not require an account.

**Is a backend server required?**  
No server is needed for ordinary use.

**Will it run when I am offline?**  
Yes. After the first load, the app can be used without an internet connection.

**Where does the application save my information?**  
Your data is stored locally in the browser on your device.

**How can I save my configuration?**  
Open settings and use the export backup function.

**What should I do if the display or data appears out of sync?**  
Refresh the page, verify that the browser can use local storage, and restore a backup if necessary.
